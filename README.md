# Personal Portfolio

Personal portfolio website of Haqiq Azeem Khan, built for CS313 Web Engineering.
Lab 2 made the five pages; Lab 3 (HTML Advanced - Personal Portfolio II) moved all styling into
one external stylesheet, laid the pages out with float and clear, and published the site with
GitHub Pages.

Live site: https://haqiqak.github.io/lab3-portfolio/

## Pages

- index.html - home page, about me and a quick summary
- hobbies.html - writing, reading, field hockey and game development
- skills.html - programming and spoken languages
- gallery.html - image gallery of six pictures, arranged with float and clear
- contact.html - email, GitHub and Substack links

## Structure

```
lab3-portfolio/
├── index.html
├── hobbies.html
├── contact.html
├── gallery.html
├── skills.html
├── css/
│   └── style.css
├── images/
│   ├── photo1.jpg
│   ├── ...
│   └── photo6.jpg
└── README.md
```

All styling lives in css/style.css. There is no JavaScript and no CSS framework.
Gallery images are from Wikimedia Commons and Wikipedia.
